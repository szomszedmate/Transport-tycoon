# Controls

## UI
- U : toggle UI

## Building
- 1–4 : Select road type (Preview)
- 5-7 : Select bridge type (Preview)
- B : Create bus preview
- R : Rotate preview
- Left click : Place
- Right click : Cancel preview
- O : Cat

## Destroy Mode
- X : Toggle destroy mode
- Left click : Destroy building

## Vehicles
- C : Cancel planning route
- Left Click (Hold) : Add road to route
- Right Click (Hold) : Remove road from route
- Enter : Confirm route
- R : Reset route

## Camera
- W : Forward
- A : Left
- S : Back
- D : Right
- E / Scroll up : Up
- Q / Scroll down : Down
- Middle click (Hold) : Rotate camera (Free look)
- Middle click (Double) : Reset rotation
- Left arrow : Rotate camera left
- Right arrow : Rotate camera right
- Down arrow : Rotate camera down
- Up arrow : Rotate camera up
- Left Shift (Hold) : Increase speed

## System
- Escape : Open menu

## Misc
- Escape : End credits
