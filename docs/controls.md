# Controls

## Building
- 1–4 : Select road type (Preview)
- B : Create bus preview
- R : Rotate preview
- Left click : Place
- Right click : Cancel preview


## Destroy Mode
- X : Toggle destroy mode
- Left click : Destroy building

## Vehicles
- C : Start / Cancel planning route
- Left Click (Hold) : Add road to route
- Right Click (Hold) : Remove road from route
- Enter : Confirm route
- R : Reset route

## Camera
- W : Forward
- A : Left
- S : Back
- D : Right
- E / Scroll up : Up
- Q / Scroll down : Down
- Middle click (Hold) : Rotate camera (Free look)
- Middle click (Double) : Reset rotation
- Left Shift (Hold) : Increase speed

## System
- Escape : Open menu
- 9 : Debug Grid (Log locations)
