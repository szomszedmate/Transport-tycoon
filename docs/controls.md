# Controls

## Building
- 1–4 : Select road type (Preview)
- B : Create bus preview
- R : Rotate preview
- Left click : Place
- Right click : Cancel preview


## Destroy Mode
- X : Toggle destroy mode
- Left click : Destroy building

## Vehicles
- C : Start / Cancel planning route

## Camera
- W : Forward
- A : Left
- S : Back
- D : Right
- E / Scroll up : Up
- Q / Scroll down : Down
